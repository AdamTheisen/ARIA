# ARIA Development

## AI-assisted development

ARIA has been developed with substantial assistance from **OpenAI ChatGPT**.

For ARIA v0.16.4, the ChatGPT model used was:

- **GPT-5.6 Sol**
- Platform: OpenAI ChatGPT

ChatGPT assistance has included:

- software architecture and API design
- Python code generation and refactoring
- debugging and error diagnosis
- Streamlit dashboard development
- documentation drafting and maintenance
- test scaffolding
- performance optimization ideas
- data-processing and visualization workflow design

The use of ChatGPT does **not** constitute scientific validation. Human
maintainers are responsible for reviewing code, testing external data-source
behavior, validating numerical methods, checking scientific correctness, and
approving releases.

When future releases use a materially different AI model or system, this file
should be updated so the development provenance remains visible.
