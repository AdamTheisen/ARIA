# ARIA Visualization Conventions

- Radar reflectivity defaults to -30 to +70 dBZ.
- Model and observation panels should share a horizontal colorbar.
- Difference panels use a separate horizontal diverging colorbar centered on zero.
- Single-radar 3-D provides detailed local storm-volume exploration.
- Regional Radar retains a detailed multi-radar 3-D volume option.
- 3-D scenes use black state outlines for geographic context.
- 3-D axis ranges are pinned to the actual radar grid so an empty isosurface
  cannot cause state outlines to zoom the view to the entire United States.
